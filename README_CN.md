## 💡 如何使用MTProto代理？

1. 复制 `all_proxies.txt` 中的一行  
2. 在手机或桌面浏览器打开  
3. Telegram会自动提示连接代理

你也可以手动将代理链接粘贴到Telegram“数据和存储”设置下的“代理”中。
